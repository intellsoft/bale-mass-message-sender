# 🚀 بله‌رسان (Bale-Rasan)
### سامانه هوشمند و بی‌واسطه ارسال پیام انبوه در پیام‌رسان بله

**بله‌رسان** یک ابزار حرفه‌ای و استراتژیک برای مدیران کسب‌وکار و بازاریابان محتوایی است که امکان ارسال پیام‌های اطلاع‌رسانی و تبلیغاتی را به صورت انبوه، مستقیم و با کمترین هزینه فراهم می‌کند. این نرم‌افزار با حذف واسطه‌ها، به طور مستقیم به **API رسمی سرویس سفیر بله** متصل شده و تمامی محدودیت‌های پنل‌های واسطه را از بین می‌برد.

---

## ✨ قابلیت‌های کلیدی (Key Features)

*   **اتصال مستقیم و بی‌واسطه:** بهره‌گیری از پروتکل‌های رسمی پلتفرم بله جهت ارسال پیام با تعرفه واقعی و بدون کارمزد اضافی.
*   **پشتیبانی از محتوای چندرسانه‌ای:** امکان ارسال هم‌زمان متن، تصاویر و فایل‌های صوتی (مانند کاتالوگ‌های صوتی یا پادکست‌های معرفی محصول).
*   **زمان‌بندی هوشمند (Scheduler):** برنامه‌ریزی دقیق کمپین‌ها برای تاریخ و ساعت مشخص بر اساس تقویم شمسی.
*   **مدیریت حرفه‌ای مخاطبان:** قابلیت وارد کردن لیست شماره‌ها از طریق فایل‌های **CSV و اکسل**، گروه‌بندی و ویرایش آسان مخاطبان.
*   **گزارش‌گیری شفاف:** ارائه گزارش‌های دقیق در قالب اکسل شامل وضعیت موفقیت یا خطای هر شماره ارسالی برای تحلیل دقیق بازگشت سرمایه (ROI).
*   **کنترل کامل عملیات:** امکان توقف (Pause) و ادامه (Resume) فرآیند ارسال در هر لحظه بدون از دست رفتن داده‌ها.
*   **امنیت و محرمانگی:** ذخیره‌سازی تمامی کلیدهای API و اطلاعات حساس به صورت **رمزنگاری‌شده** روی سیستم شخصی کاربر.
*   **رابط کاربری فارسی:** طراحی زیبا و کاربرپسند، مناسب برای تمامی کاربران با هر سطح از دانش فنی.

---

## 🛠 مزایای استراتژیک برای مدیران

1.  **کاهش چشمگیر هزینه‌ها:** حذف بودجه‌های زائد ناشی از کارمزدهای پنل‌های ابری و واسطه.
2.  **اتوماسیون بازاریابی:** حذف فرآیندهای دستی و وقت‌گیر و افزایش بهره‌وری نیروی انسانی.
3.  **بالاترین نرخ تعامل:** پیام‌ها مستقیماً در صندوق ورودی کاربران بله با استفاده از رسانه و ایموجی‌های بازاریابی دیده می‌شوند.
4.  **امنیت داده‌ها:** بانک شماره مشتریان شما به عنوان دارایی اصلی کسب‌وکار، تنها روی سیستم خودتان باقی می‌ماند.

---

## 📅 نقشه راه توسعه (Roadmap)

در نسخه‌های آینده، قابلیت‌های زیر به بله‌رسان اضافه خواهد شد:
*   **شخصی‌سازی پیشرفته:** درج نام مخاطب در متن پیام با استفاده از متغیرهای فایل اکسل.
*   **اتصال به وب‌سایت‌ها:** ارائه API و وب‌هوک برای اتصال به فروشگاه‌های وردپرسی و ووکامرسی جهت ارسال خودکار وضعیت سفارش.
*   **سیستم ضدبلاک (Anti-Block):** مکانیزم‌های شبیه‌سازی رفتار انسانی با تاخیرهای تصادفی.
*   **منشی هوشمند:** پاسخگوی خودکار به تعاملات مخاطبان بر اساس کلمات کلیدی.
